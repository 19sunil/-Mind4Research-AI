# 🧠 Mind4Research AI

An advanced **Multi-Agent Research Automation System** built with **Python, Streamlit, LangChain, Groq, and Tavily**.

## 🚀 Features

* Multi-Agent AI workflow
* Automated web research
* AI-generated reports
* Modern Streamlit UI
* Downloadable outputs
* Real-time processing experience

## 🤖 Agents

* Planner Agent
* Search Agent
* Analyst Agent
* Writer Agent
* Critic Agent

## 🛠️ Tech Stack

Python • Streamlit • LangChain • Groq • Tavily • BeautifulSoup

## ▶️ Run Locally

```bash id="a8mgh3"
pip install -r requirements.txt
streamlit run app.py
```

## 📌 Use Cases

* Academic research
* Market research
* Trend analysis
* Topic summaries
