# ✨ Overview

**Mind4Research AI** is a next-generation research assistant that uses a **multi-agent AI architecture** to automate deep research workflows.

Instead of relying on a single model response, multiple intelligent agents collaborate to:

* Understand the topic
* Break research into tasks
* Search the web intelligently
* Analyze findings
* Critique quality
* Produce a polished final report

This project demonstrates practical **Agentic AI**, **LLM orchestration**, and **real-world automation systems**.

# ⚙️ Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/yourusername/Mind4Research-AI.git
cd Mind4Research-AI
```

---

## 2️⃣ Create Virtual Environment

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Add API Keys

Create a `.env` file:

```env
GROQ_API_KEY=your_groq_key
TAVILY_API_KEY=your_tavily_key
```

---

# ▶️ Run Application

```bash
streamlit run app.py
```

Then open:

```text
http://localhost:8501
```
